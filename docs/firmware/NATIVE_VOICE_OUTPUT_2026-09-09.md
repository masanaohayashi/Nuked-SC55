# ボイス出力の準備処理

[解析索引へ](../../FIRMWARE_RESEARCH_INDEX.md)

`TryStepVoiceOutput`が319d..320e内の30命令を単命令C++化する。
voice[26,30,38]とff00の比較、出力の倍化/右シフト、voice[24,28,36]への
保存、ac42の表示用レベル更新を扱う。表示データの生成も従来のスレッドに
残し、UI呼び出しやスレッド移動は行わない。

PCMレジスターの読み書き、入口318c/3190付近は未置換。
それらの前後をまとめず、各命令境界で状態を公開するため、
ハードウェアアクセスの順序と周辺回路の更新間隔を維持する。
新しい確保・ロックはない。

ガードはv1.21、CP/DP=0、正規voice、traceなし。
ac42書き込みにはR1<24も要求する。条件外は状態変更せずH8に戻る。
割り込みmask/EPには依存しない。

## 検証

- 30命令×384ケース＝11,520命令境界でPC/SR/全レジスタ/SRAMがH8と一致。
  mask0..7、SR下位16通り、EP=1、24voiceを含む。
- Release oracle: 379,676ステレオフレームがビット一致。
- 同じ再生のH8 fallback: 3,568,404→3,451,710（116,694命令減少）。
- Mac Release Shared Codeを署名なしでビルド成功。

CPU時間とLogic内負荷は未測定。fallback減少率はCPU改善率ではない。

## 続き: PCMレジスターアクセス

31a7のチャンネル選択、31b0/31ce/31fbのff00設定、
31b5/31d3/3200のread latch選択、31b7/31d5/3202のラッチ読み取り、
31c5/31e3/3210の出力設定を書き換え、合計43命令にした。
これら13命令はBR=e0を追加条件とし、既存MCU_Read/Read16/Write/Write16
経由でPCMの副作用を保つ。各命令でPCを進めてからアクセスし、debtを追加しない。
入口318c/3190付近は引き続き未置換。

- 43命令×384ケース＝16,512命令境界でH8と一致。
  PCMのram1/ram2、ラッチ、チャンネル選択等のeram前の状態とsim_dirtyも比較。
  全32チャンネルとランダムなram2/ラッチ値を含む。
- Release oracle: 379,676ステレオフレームがビット一致。
- H8 fallback: 3,451,710→3,404,622（47,088命令減少）。
- Mac Release Shared Codeビルド成功（署名なし）。

CPU改善量は未測定。

## 続き: 入口と逆アセンブルの訂正

318c/3190/3195/319aの4命令を追加し、318c..3210の47命令をカバーする。
318cはSRの割り込みmaskを7にし、元の制御レジスター書き込みと同じ
ex_ignore=1を設定する。

既存ASMの3190..3199は命令境界が崩れている。実際のデコーダーで確認した
境界は3190→3195→319a。3190は5byteの即値書き込みで、
voice[-26]へ低位byteのffを保存する。3195はvoice[0]と14の比較。
319aはcarryなしで3363へ分岐する。ASMにある3194からの命令は実際の境界ではない。

- 47命令×384ケース＝18,048命令境界でH8と一致。
  PC/SR/レジスタ/SRAM/PCM状態に加えex_ignoreも比較する。
- Release oracle: 379,676ステレオフレームがビット一致。
- H8 fallback: 3,404,622→3,383,922（20,700命令減少）。
- Mac Release Shared Codeビルド成功（署名なし）。

領域の命令カバーは条件付き。ガード外と他ROMはH8へ戻るため、
全ファームウェアのC++化完了を意味しない。CPU改善量は未測定。

## 続き: 5855のパラメーター再反映

5855..5898の25命令を追加。voice状態が0または14以上なら書き込みをせず戻る。
それ以外はvoice[-2]でPCMチャンネルを選択し、voice[30,26,52,58,38,72]を
PCMレジスター18,16,12,14,1a,10へ順に反映する（レジスター番号は16進）。
voice[104]を上位byte、voice[102]を下位byteに組み立てて1cへ反映する。
入口で割り込みmaskを7、出口で0にし、RTSまで各命令境界を保持する。
条件・SRフラグ・PCM副作用を保持し、I/Oをまとめて前倒ししない。

- 出力ヘルパー全72命令×384ケース＝27,648境界でH8と状態一致。
  PCM状態、ex_ignore、スタックへの影響も比較する。
- Release oracle: 379,676ステレオフレームがビット一致。
- H8 fallback: 3,186,852→3,062,964（123,888命令減少）。
- Mac Release Shared Codeビルド成功（署名なし）。

CPU改善量は未測定。
