# ボイス共有先の検証と参照付け替え

`TryStepVoiceLink`で3985..39f5の41命令を単命令C++化。
voice[-115]が非ゼロなら、voice[-2]からc84eの24要素ポインター表を引く。
共有先の状態が12以下で、両ボイスの+155/+152/+156の値が一致すれば
3d44へ進む。不一致の場合は自分の表要素とvoice[-115]をクリアし、
同じ共有先を参照する他要素を自分のvoiceへ付け替える。

その後voice[0]を保存し、割り込み許可→4NOP→禁止を経て再比較する。
状態が変わっていれば戻り、変わっていなければ39f6以降の計算へ進む。
この観測区間を保つため、ループやNOPの一括省略はしない。

v1.21、CP/DP=0、正規voice、traceなしが条件。
ポインター表は偶数index0..46、共有先を読む命令は正規voiceに限定。
条件外はH8に戻る。新しい確保・ロック・スレッド移動はない。

## 検証

- 41命令×384ケース＝15,744境界でPC/SR/全レジスタ/ex_ignore/SRAMが一致。
- Release oracle: 379,676ステレオフレームがビット一致。
- H8 fallback: 3,062,964→3,052,564（10,400命令減少）。
- Mac Release Shared Codeビルド成功（署名なし）。

CPU改善量は未測定。39f6以降の計算と3d44の共有処理は引き続き解析・置換が必要。
