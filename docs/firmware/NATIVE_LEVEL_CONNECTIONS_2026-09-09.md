# 音量LFOの接続と最終変換

[解析索引へ](../../FIRMWARE_RESEARCH_INDEX.md)

`TryStepLevelConnections`で30ff..312aと30eaの18命令を単命令C++化。
2組の引数はvoice[-122,+142,-96]と[-88,+150,-62]。
BSRは各2byte命令の戻りアドレスを既存スタックヘルパーで保存する。
最終変換はR4二乗の上位wordに0x208を掛け、上位word255を境に
バイト入れ替えまたはffffへ飽和する。30ea/3126/312aのRTSも扱う。

v1.21、CP/DP=0、正規voice、traceなしを要求し、mask/EPに依存しない。
debtを追加せず、各命令のレジスタ/SR/スタック状態を公開する。
音声スレッドを移動せず、確保・ロック・UI呼び出しを追加しない。

## 検証

- 18命令×384ケース＝6,912命令境界でH8とPC/SR/レジスタ/SRAMが一致。
  mask0..7、SR下位16通り、EP=1、正規voice24個を含む。
- Release oracleで379,676ステレオフレームがビット一致。
- H8 fallback: 3,574,541→3,569,004（5,537命令減少）。
- Mac Release Shared Codeを署名なしでビルド成功。

CPU時間・Logic内負荷は今回未測定。音量合成前段にはH8が残る。

## 続き: 倍率変換と符号付き補正

30d6..30fdの残り17命令を追加し、合計35命令に拡張。
0x830e/0x8208の乗算、下位wordの倍化から上位wordへのcarry伝播、
voice[+138]の符号付き補正と減算時のゼロ飽和を再現する。
ADDXの累積Zを含め、単命令ごとの状態と割り込み境界を維持する。

- 35命令×384ケース＝13,440命令境界でH8と一致。
- Release oracle: 379,676ステレオフレームがビット一致。
- 同じ再生のH8 fallback: 3,569,004→3,568,829（175命令減少）。
- Mac Release Shared Codeビルド成功（署名なし）。

今回の追加によるCPU時間の改善は未測定。309b..30d5の単命令経路は未置換。

## 続き: 音量合成の入口

309b..30d4の24命令を追加し、接続ヘルパーは合計59命令になった。
パート対応c8e4、音量ab36、voice[46]のパッチ値、マスター音量8002、
voice[48]の選択補正を読み、8/16bit乗算とword間carryを再現する。
MOV.Bはレジスタ上位byteを保持し、SWAPはwordのNZを更新する。
動的な読み取り先がSRAM外なら状態を変更せずH8へ戻す。
309bの既存バッチが使えない場合にも単命令C++経路を選べるようにした。

- 59命令×384ケース＝22,656命令境界でPC/SR/レジスタ/SRAMが一致。
- Release oracle: 379,676ステレオフレームがビット一致。
- 同じ再生のH8 fallback: 3,568,829→3,568,404（425命令減少）。
- Mac Release Shared Codeビルド成功（署名なし）。

309b..3187は変調サブルーチンを含め単命令C++経路を持つが、
ガード条件外の状態と他ROMは引き続きH8へ戻る。CPU改善量は未測定。
