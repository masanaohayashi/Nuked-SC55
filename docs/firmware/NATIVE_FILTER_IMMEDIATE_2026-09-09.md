# フィルターEGの初期値と保持

[解析索引へ](../../FIRMWARE_RESEARCH_INDEX.md)

`TrySetFilterImmediate`が4494/4553から4662までの各5命令をC++化。
初期値側はvoice36とvoice-48をゼロ化し、始点84をR5と出力32へコピー。
保持側は余り時間20をゼロ化し、目標86をR5と出力32へコピーし、
voice-48を8へ設定する。最後のMOVの違いによるSR差も維持する。

v1.21、CP/DP/EP=0、mask7、traceなし、正規voiceを要求。
debt=4で5命令分の時間を保ち、PCMバス書き込みを含めない。
既存audio経路に確保・ロック・UI呼び出しは追加しない。

## 検証

- 2,304ケースでH8とPC/SR/レジスタ/SRAM/命令数が一致。
- Release oracleで379,676ステレオフレームがビット一致。
- H8 fallback: 3,587,004→3,582,174（4,830命令減少）。
- Mac Release Shared Codeを署名なしでビルド成功。

## 残存経路

今回oracleに4443..4856の命令別fallback集計を追加した。
再生中の当該領域は6,783命令がまだH8で動く。47fbを含むLFO合成入口は
100回、後続加減算は各50回など。バッチ処理の適用外経路が残るため、
領域全体の完全置換とみなさない。次にガード条件と非マスク経路を確認する。
この測定は限定再生条件であり、全音色・ROM・ホスト負荷の証明ではない。
