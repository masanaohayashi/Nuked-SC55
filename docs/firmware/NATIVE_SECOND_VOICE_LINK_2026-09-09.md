# 第2変調系の共有先検証

`TryStepSecondVoiceLink`で3a7a..3aacと3aeb..3b25の40命令を単命令C++化。
第1系3985の同型処理との主な差分は次の通り。

|項目|第1系|第2系|
|---|---|---|
|共有フラグ|voice[-115]|voice[-81]|
|参照表|c84e|c87e|
|比較パラメーター|+155/+152/+156(word)|+155/+153/+158(word)|
|一致時|3d44へ分岐|3aaeの共有コピーへ継続|
|通常計算入口|39f6|3b26|

共有先の状態は12以下を要求。共有不可なら参照をクリアして同じ共有先を
指す他ボイスを付け替える。割り込み許可・4NOP・再禁止を跨いで状態を
再確認する点は第1系と同じ。3a7dのBEQは3byteの長分岐である。

v1.21、CP/DP=0、正規voice、traceなしを要求。テーブルindexは偶数0..46、
共有先へのアクセスも正規voiceに限定する。条件外はH8へ戻す。
確保・ロック・スレッド移動・周辺更新回数の変更はない。

## 検証

- 40命令×384ケース＝15,360境界でPC/SR/全レジスタ/ex_ignore/SRAMが一致。
- Release oracle: 379,676ステレオフレームがビット一致。
- H8 fallback: 2,922,564→2,912,164（10,400命令減少）。
- Mac Release Shared Codeビルド成功（署名なし）。

CPU改善量は未測定。3b26以降は既存の条件付きLFOバッチへ接続するが、
バッチのガード外の単命令経路は別途置換が必要。
