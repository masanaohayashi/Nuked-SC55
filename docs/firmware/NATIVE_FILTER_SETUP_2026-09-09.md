# フィルター設定転送・初期化

TryStepFilterSetupでSC-55 v1.21の43d1..4440、34命令を単命令置換。
パッチbyte50..54を7fでマスクしvoice[74..78]へ転送する。
4494呼び出し後、voice[20]/[10]をクリアして履歴[-22]/[-24]を初期化。
ac5aの周期値をac5cに退避、1に変更して44a3を呼び、周期値を復元する。
最後にcaf4[R1]によって56d9/4858へ分岐。

BSRのPC/スタック操作は命令ごとに保持。スタックは偶数のSRAM範囲を対象とする。
パッチはEP=0のROM/SRAM、EP=1〜4のROMから参照する。
割り込み境界を維持し、動的確保・ロック・UI呼び出しは追加しない。
