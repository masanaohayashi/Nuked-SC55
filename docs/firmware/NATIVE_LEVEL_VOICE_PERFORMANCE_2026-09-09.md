# 音量・ボイス出力追加後のRelease CPU時間

前回フィルター補間の測定時点のバイナリと、318c..3210まで追加した現状を比較。
間にフィルターの未マスク経路、音量合成、ボイス出力を追加しているため、
ボイス出力単独の効果ではない。

製品のNukedSC55Emulator/backendを使う既存ローカル測定器。
48kHz、128samples、120秒相当。起動/ウォームアップを除外し
CLOCK_THREAD_CPUTIME_IDを測る。ビルド終了後、各モードで旧→新→新→旧を逐次実行。
chordはprogram48の24音、idleはノートを送らない起動後の状態。

|条件|旧1 秒|新1 秒|新2 秒|旧2 秒|
|---|---:|---:|---:|---:|
|24音|3.998617|4.028971|4.112124|4.085707|
|アイドル|2.082374|2.093813|2.093699|2.066221|

平均は24音で旧4.042162秒、新4.070548秒（約0.70%増）、
アイドルで旧2.074298秒、新2.093756秒（約0.94%増）。
この比較では高速化を確認できない。各2回なので統計的に確定した回帰とも
断言できないが、命令デコードの置き換え数をCPU改善の根拠にはできない。
次は単命令の追加だけでなくディスパッチ費用・周辺更新を含めて優先順位を検討する。

24音のpeak=.642068/RMS=.121042、idleは両方0、全実行で
H8cyclesDelta=2400053748、underruns/dropped=0。
この集計値は音声ビット一致の証明ではない（別途oracleで確認済み）。
Logic、UI、プラグインラッパーを含まないためLogicのCPUメーターとは比較しない。
ログのnative=0はNUKED_SC55_NATIVE_PREVIEWの値であり、今回のv1.21置換の無効化ではない。
