# フィルターLFO合成

[解析索引へ](../../FIRMWARE_RESEARCH_INDEX.md)

`TryModulateFilter`が47fb..4856（RTS手前）をC++化する。
R2/R3の深さを符号別に処理し、R6のLFO波形を掛け、丸めた値をR5へ反映。
両深さが正なら和を0x1800へ制限。両方負なら両レジスタを反転するが、
ROMには加算がなくR2だけを0x1800へ制限する。この差を維持している。
異符号の深さは16bit和の符号で方向を選ぶ。

波形の絶対値を16bitで倍化して乗算し、積の下位wordへ0x8000を加える。
そのcarryをADDX/SUBXに渡す。ADDXの累積Z、SUBXの通常Z、正側overflowの
32767飽和、負側borrowのゼロ化を含め、最終SRとレジスタを再現。

v1.21、CP=0、mask7、traceなしを要求。レジスタ演算のみでDP/EPに依存しない。
debtで命令数を保持し、RTSとスタック操作は次のステップに残す。
既存audio経路に確保・ロック・I/O・UI呼び出しを追加しない。

## 検証

- 7,679ケースでH8とPC/SR/レジスタ/SRAM/命令数が一致。
  0x1800前後、正負境界、最大値、丸め、乱数を含む。
- Release oracle native-tvaで379,676ステレオフレームがビット一致。
- H8 fallback: 3,881,858→3,721,792（160,066命令減少）。
- Mac Release Shared Codeを署名なしでビルド成功。

CPU時間・Logic内負荷は今回未測定。命令数減少はCPU改善率ではない。
呼び出し前後、後段設定、PCM出力にはH8が残り、完全置換ではない。
