# ボイス補正カーブ

TryStepVoiceCurveでSC-55 v1.21の4cbb..4d21、40命令を単命令置換。
voice[-2]からR1を読み、c8fc[R1]を取得する。
パッチbyte30の下位4bitを倍化してページ3のdd42テーブルを引き、
さらにc8fc値を加えた間接アドレスからbyteを読む。

パッチbyte32と64との差で符号を選択し、テーブル値を128中心に補正。
679aの係数とのbyte乗算・倍化・SWAP後、128への加減算と67c6参照を行い、
voice[-54]へ保存する。入力差がゼロ等の迂回経路では256を保存する。
フィルター側で比較済みの演算と同形だが、PC・入力パッチ・保存先は別物。

## 命令境界の訂正

4ccdと4cd9は4バイトのLDC.W即値（DP=3と0）。
線形逆アセンブルのPJSR/PJMP表示はここからの境界ずれであり実行命令ではない。
正しい境界は4ccd→4cd1→4cd5→4cd7→4cd9→4cdd→4cdf→4ce2。
ROMの実バイトを確認し、H8デコーダーとの1命令比較でPC/DP/ex_ignoreを確認する。

dd42参照は偶数0..30、679aは0..255、67c6は偶数0..510に限定。
パッチはEP=0のROM/SRAMとEP=1..4のROMを対象とし、範囲外はH8へ戻す。
割り込み境界・NZVCを維持し、RT経路の動的確保やロックは追加しない。
全体の置き換えは未完了。次の4d26以降はこのヘルパーの対象外。
