# 割り込み可能なグライド

[解析索引へ](../../FIRMWARE_RESEARCH_INDEX.md)

`TryStepPitchGlide`で5175..51e7を1命令境界ずつC++実行する。
既存のマスク区間向け一括処理を維持し、それが使えない場合に接続。
全128レートの参照、elapsed積、符号付き24bitの減衰・ゼロ制限、
現在音程への加算を扱う。グライド量ゼロ時は参照元を読み出さない。
SR/レジスタ/SRAM/PCをその命令時点で更新し、debtは増やさない。
既存の割り込み・周辺装置の12cycle刻みを保つ。RT確保・ロック・UI呼出しなし。

Release oracleの`native-tva`で6,040ケースの各命令境界がH8と一致。
全レート、正負境界、桁上がり、ゼロ量での無効参照元を含む。
不適格ROM/ページ/trace/voiceの拒否は状態不変。
参照元範囲の検証は5193、レート添字の検証は5197で行い、
拒否時はその命令の直前からH8へ戻す。
起動・24音・controller・portamento・Note Offの379,676フレームがビット一致。
非マスクグライドだけの実再生到達回数は今回計数していない。
Mac Release Shared Code（署名なし）のビルド成功。

負荷改善率、ホスト内動作、Windows/Linux、全音色は未検証。
非マスクの音程変換・キャッシュ更新、他EG/MIDI/GS/ボイス管理等は残る。
v1.21専用の部分置換であり、完全置換は未完了。
