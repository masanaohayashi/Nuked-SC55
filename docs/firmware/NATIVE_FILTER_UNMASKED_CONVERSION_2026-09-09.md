# 割り込み可能なカットオフ変換

[解析索引へ](../../FIRMWARE_RESEARCH_INDEX.md)

`TryStepFilterConversion`が4443..47f7のうち計374命令を1命令ずつ実行する。
7612のテーブル補間、共鳴設定の最低値8、7816の制限テーブル、
上限e600、voice36への保存までを扱う。
バイト操作は上位byteを保持し、SWAPのwordフラグ、CLRのcarryクリア、
MOVのcarry維持、MULの32bitフラグも再現する。

後半478e..47f7も追加した。差分の絶対値、上位byte切り上げ、指数テーブル、
SHLL/SHLRとSCB/eqループ、丸め、voice38への符号化出力を扱う。
SCB/eqはZが立つと減算せず、Zが下りている時だけR3を減算する。
RTSは接続部の既存単命令処理へ戻す。

46dd..4739のレゾナンス目標・1段追従・7714上限制御も追加。
byte加減算は上位byteを維持し、コントローラー参照はSRAM内を要求する。
一括処理が適用可能な時は既存TryAdjustFilterResonanceを優先する。

4662..46c0の基準値補正も追加。コントローラー中心64、増分上限16、
bit2による補正抑制、EGの正負別飽和、voice136の符号付きオフセットを扱う。
BTSTはZ以外を保持し、各MOV/CLR/加減算のフラグ差を維持する。
既存TryAdjustFilterBaseが使える条件は変更しない。

45b6..45fbと4654..465fの位相更新・短時間出力も追加。
DIVの商/余りとoverflow時のレジスタ保持、ADDXの累積Z、SUBXのborrowを再現。
ゼロ除算は状態変更前にH8へ戻す。

45fe..4652の符号付き補間41命令も追加した。始点/目標の符号による4経路、
異符号差分の32767飽和、16bit反転、乗算上下word、最終加減算を維持する。

44a3..44fcのアタック時間計算38命令、4494/4553の初期値・保持10命令を追加。
bit4によるcontroller適用条件、中心64のbyte演算、6f12テーブル、2段の倍率と
積上位word255での飽和を保持。元のmask7バッチを優先し、適用外のみ単命令処理。

44ff..4551のディケイ36命令、4564..45b4のリリース35命令も追加。
controllerはpart+21/+22、第1倍率はvoice-44/-42、第2倍率は両者voice-38。
リリース末尾は45b6へそのまま進み、ディケイの分岐1命令とは区別する。

4443..4492の段階遷移27命令も追加。無効化、位相完了、次段階・初期化・
実行先テーブル、3組の目標/レートコピーを単命令実行する。
テーブル添字は0..22の偶数に限定し、それ以外はH8へ戻す。

v1.21、CP/DP=0、正規voice、traceなしを要求。EPと割り込みマスクに依存せず、
各命令境界で状態を公開する。テーブル添字は既知のROM範囲に制限し、
範囲外は変更前にH8へ戻す。debtなし。既存mask7のバッチ処理は維持する。
確保・ロック・I/O・UI呼び出しは追加しない。

## 検証

- 374命令×384ケース＝143,616命令境界でPC/SR/レジスタ/SRAM一致。
  mask0..7、SR下位16通り、EP=1、テーブル添字を含む。
- Release oracleで379,676ステレオフレームがビット一致。
- フィルター領域fallback: 5,283→4,025（1,258命令減少）。
- 後半追加後は4,025→2,946（さらに1,079命令減少）。
- レゾナンス追加後は2,946→2,196（さらに750命令減少）。
- 基準値追加後は2,196→1,346（さらに850命令減少）。
- 位相更新追加後は1,346→962（さらに384命令減少）。
- 補間追加後は962→800（さらに162命令減少）。
- アタック追加後は800→125、初期値追加後は125→0。
- Mac Release Shared Codeを署名なしでビルド成功。

この再生条件では4443..4856のH8 fallback=0になった。
ディケイ/リリース追加後もfallback=0を維持（測定条件では命令数に変化なし）。
段階遷移追加後、逆アセンブルの4443..4856にある428命令アドレスすべてが
conversion/modulation/connectionsの単命令テスト対象に含まれることを照合した。
これはアドレスの網羅であり、全入力・不正添字・全割り込み履歴の網羅ではない。
DPやtrace、添字などのガードでH8へ戻る条件は引き続き存在する。
限定再生条件でのゼロを全音色・全分岐・全ROMの完全置換とはみなさない。
命令数削減はCPU時間の削減率ではなく、Logic内負荷は未測定。
