# 割り込み可能なピッチ補間と呼び出し接続

`TryStepPitchEnvelope`は5060..50cfの補間を命令境界ごとに実行する。
`TryStepPitchConnections`は初期化の呼び出し、elapsed復元、後段分岐、
変調の引数ロードと呼び出し、および5367/53e4の復帰を扱う。
割り込みをマスクせず、各命令のレジスタ・SR・SRAMを即時更新する。
debtは追加せず、既存の12cycle単位の割り込み・周辺装置更新を維持する。
v1.21専用。メモリ確保、ロック、UI呼び出しは追加していない。

Release oracleの`native-tva`で補間5,398ケースの各命令境界と、
接続19命令×384ケースのPC/SR/全レジスタ/SRAMをH8と比較した。
起動・24音・controller・portamento・Note Offの379,676ステレオフレームが
ビット一致。実再生で割り込み可能な補間の入口を25回通過。
接続の単体テストは正常な偶数SRAMスタックを使用。
異常スタック時は既存スタックヘルパーを利用するが単体検証は未実施。

この追加についてホスト内性能・Windows/Linux・全音色は未検証。
割り込み可能な後段補正/変調/変換等のH8経路は残る。完全置換ではない。
既存資料の「補間・呼び出し・復元は未実装」という残件の一部を本変更で更新する。

## 後続: 復帰経路

56d8のRTSと56d9のスタック加算を追加。後者はCAF4分岐から呼び出し元の
戻り先をスキップして56dbへ進む命令であり、以降の処理はまだH8。
接続テストを21命令×384ケースへ拡張し、スタック加算の符号境界・桁上がり・
16bit wrapを含め8,064命令境界が一致。音声379,676フレームもビット一致。
Mac Release Shared Code（署名なし）のビルド成功。ホスト内の動作・性能は未検証。
