# 割り込み可能な音程補正・チューニング

[解析索引へ](../../FIRMWARE_RESEARCH_INDEX.md)

`TryStepPitchAdjustment`を50cf..510aと5124..5175へ追加。
controller由来の符号付き補正、全体チューニング、part別チューニングを扱う。
従来の一括C++処理が割り込みマスク等の条件で使えない場合に、1命令ずつ実行する。
各命令のPC/SR/レジスタ/SRAMを更新し、debtは追加しない。
既存の12cycle刻みの割り込み・周辺装置更新を維持する。RT確保・ロック・UI呼出しなし。

## 検証

- controller補正とチューニング各7,585ケースの各命令境界でH8と状態一致。
  正負境界、24bit桁上がり・wrap、下限制限、controller補正の127000上限制限を含む。
- trace/ROM適格性/ページ/voiceガード拒否で状態不変。
  part参照は514dでvoice番号範囲、5153でpartテーブルの範囲・アラインメントを確認。
  無効ならその命令の直前でH8へ戻す（途中まで進んだ処理全体を巻き戻さない）。
- 実再生で新経路を各25回通過。379,676ステレオフレームがH8とビット一致。
- Mac Release Shared Code（署名なし）ビルド成功。

検証コマンドは既存oracleのRelease buildと`ctest -R '^native-tva$' -V`。
ホスト内CPU負荷、全音色、Windows/Linuxは未検証。今回の改善率は未測定。
