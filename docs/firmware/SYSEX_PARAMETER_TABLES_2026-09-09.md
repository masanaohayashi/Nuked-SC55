# v1.21 SysExパラメータテーブル

`cpu-roles --system`で実行中ROMマップから採取。全て16進（kindのみ10進）。
テーブルの仕様は [受理・リセット経路](SYSTEM_SYSEX_RESET_2026-09-09.md) を参照。
destinationはd6e8/d726では絶対RAM、d7dc/d982ではpart先頭からのオフセット、
dc16ではdrum map先頭からのオフセット。argは型依存で副作用番号・長さ・bit mask等。
lower/upperは値のclamp境界であり、個々のメッセージの受理条件の全てではない。
テーブルに存在することと単バイト書込で受理されることを混同しない。
