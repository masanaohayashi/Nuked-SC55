# フィルター深度の最大値選択

TryStepFilterMaximumでSC-55 v1.21の418c..41bd、19命令を単命令置換。
voice[84]を初期値とし、voice[86/88/90/92/94]を順に符号付き比較して
最大値をR3に残す。同値ではMOVを実行する元のBGT分岐も維持。
続いてR4をクリアしてvoice[163]をbyte読み込み、voice[46]をR2へ読み込む。
比較命令は全NZVC、分岐は既存SR、MOVはC維持でNZVを更新する。

割り込み境界を維持し、動的確保・ロック・UI呼び出しは追加しない。

加算側はvoice[162]のbit2が立っていれば省略し、それ以外では増分を16に、
結果を127に制限する。続くSWAP R4とTST R3も置換。
