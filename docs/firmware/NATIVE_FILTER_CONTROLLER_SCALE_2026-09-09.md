# フィルターのコントローラー係数

TryStepFilterControllerScaleでSC-55 v1.21の4327..4379、32命令を単命令置換。
127-c95c[R1]とパッチbyte62から、voice[-40]へ保存する係数を作る。
負側はbyte乗算後、1f41以上なら4、それ未満は(1fc0-積)×810の上位word。
正側は1fc0-積を除数にし、32未満ならffff、それ以外は1fc000を除算。
補正ゼロでは256を保存する。DIVXUの商オーバーフロー時はレジスタを維持してVを設定。
ゼロ除算はH8へフォールバックする。

EP=0のROM/SRAM、EP=1〜4のROMからのパッチ参照に対応。
679aテーブルの参照条件はR3=0..255。割り込み境界を維持し、
動的確保・ロック・UI呼び出しは追加しない。

- 全32命令×384＝12,288境界でPC/SR/全レジスタ/DP/EP/ex_ignore/SRAM一致。
- 379,676ステレオフレームがビット一致。
- 同じ再生のH8 fallbackは2,853,938→2,853,738。
- Mac Release Shared Codeビルド成功（署名なし）。
