# 割り込み可能な音程差→PCMレート変換

[解析索引へ](../../FIRMWARE_RESEARCH_INDEX.md)

`TryStepPitchConversion`は51e7..527cの変換を各命令境界でC++実行する。
符号付き24bit差、12000単位の除算、2段のテーブル参照と乗算、
回転・ビット操作、負側のシフト、正側の飽和、C8B0への保存を扱う。
シフトループも一括で飛ばさず、SCBのレジスタ減算と分岐を別ステップとして残す。
debtは追加しない。既存の割り込み・周辺装置更新を維持する。

EXTSは既存H8実装が拡張前の値でフラグを計算する挙動に合わせる。
この追加はH8命令実装の修正を兼ねない。除算の商overflow時もレジスタを維持する。
v1.21/CP/DP/voice/traceガードを保ち、無効テーブル添字ならH8へ戻す。
RT確保・ロック・UI呼出しなし。

Release oracleの`native-tva`で5,398ケースの各命令後のPC/SR/レジスタ/SRAMが一致。
既存ガード拒否時の状態不変と、379,676ステレオフレームのビット一致を確認。
非マスク変換専用の実再生到達カウンターは今回は追加していない。
Mac Release Shared Code（署名なし）のビルド成功。
ホスト内負荷・全音色・Windows/Linuxは未検証、改善率は未測定。

非マスクのキャッシュ補正527c..5367、他EG/MIDI/GS/ボイス管理等は残る。
