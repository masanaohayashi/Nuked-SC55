# フィルター深度の係数設定

TryStepFilterDepthでSC-55 v1.21の3f05..3f2f、18命令を単命令置換。
voice[-46]を読み、パッチbyte44から7512テーブルの係数を取り出して
voice[-36]へ保存する。パッチbyte45と64の差、およびR2の符号ビットで
後続の乗算経路3f31/3f63を選択する。必要なNEG、BTSTのZのみの更新も再現。

EP=0のROM/SRAM、EP=1〜4のROMからのパッチ参照に対応。
テーブルは偶数インデックス0..510、その他はH8へ戻す。
割り込み境界と命令ごとの周辺回路更新を維持する。
動的確保・ロック・UI呼び出し・スレッド変更は追加していない。

- 18命令×384＝6,912境界でPC/SR/全レジスタ/DP/EP/ex_ignore/SRAM一致。
- native-tva: 379,676ステレオフレームがビット一致。
- 同じ再生のH8 fallbackは2,859,767→2,859,467。
- Mac Release Shared Codeビルド成功（署名なし）。

CPU改善量、Logicでの動作は未測定。

## 両符号経路の乗算

3f31..3f49と3f63..3f7bの各12命令を追加、合計42命令。
R2×R3の32ビット積をADD/ADDXで倍化し、R6の下位byteで79f2テーブルを参照。
その係数との乗算・倍化を行い、MOV.B/SWAPで積の中間16ビットを取り出す。
合成に使うvoice[84]も読み出す。
ADDXのC入力と累積Zを維持し、単命令境界で実行する。
79f2テーブルのネイティブ参照条件はR3=0..255。

- 全42命令×384＝16,128境界でPC/SR/全レジスタ/DP/EP/ex_ignore/SRAM一致。
- 379,676ステレオフレームがビット一致。
- 同じ再生のH8 fallbackは2,859,467→2,859,167。
- Mac Release Shared Codeビルド成功（署名なし）。

CPU改善量は未測定。

## 合成・飽和処理

3f4c..3f61と3f7e..3f8dの19命令を追加、合計61命令。

この追加で3f05..3f8dの命令列を覆う（ガード外は既存H8に戻す）。
