# 割り込み可能なピッチ変調

[解析索引へ](../../FIRMWARE_RESEARCH_INDEX.md)

`TryStepPitchModulation`は5368..53e4の変調を1命令境界ずつ実行する。
既存の一括処理を使えない割り込み許可中にも、符号別の振幅合成、6000制限、
波形との乗算、丸め、24bit音程の加減算・負側のゼロ制限をC++で実行する。
レジスタ/SR/SRAMを即時更新し、debtを追加しない。RTSは既存の接続処理に委譲。
v1.21適格性、CP/DP、正規voice、trace禁止のガードは維持。
EPを使う間接参照はなく、EP=1でも許可する。確保・ロック・UI呼出しなし。

Release oracleの`native-tva`で5,398入力ケースの各命令直後の
PC/SR/全レジスタ/SRAMをH8と比較し一致。符号・桁上がり・丸め境界を含む。
ガード拒否時の状態不変も確認。既存の起動・24音・controller・portamento・
Note Offテストでは379,676ステレオフレームがビット一致。
このテストでは非マスク変調の専用到達回数は計数していない。
Mac Release Shared Code（署名なし）のビルドも成功。

負荷改善率とホスト内動作、Windows/Linux、全音色は未検証。
非マスク時のグライド・変換・キャッシュ更新、他EG、MIDI/GS、ボイス管理等は
H8が残っている。これは完全置換の完了ではない。
