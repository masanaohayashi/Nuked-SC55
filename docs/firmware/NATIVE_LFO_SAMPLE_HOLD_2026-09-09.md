# PCM由来の値を保持するLFO

`TryStepLfoSampleHold`で3cac..3ccfの14命令を単命令C++化。
R4:R5を倍化し、ブロック+22の位相を加算する。
上位wordが非ゼロの時だけPCMチャンネル30を選び、34の読み取りで
ラッチを更新し、3aのword読み取り結果をブロック+28へ保持する。
位相は+22、保持値は出力+32へ保存する。

PCM読み取りを前倒しせず、各命令の副作用と周辺更新間隔を維持。
ADDXのcarryと累積Zも再現する。
v1.21、CP/DP=0、偶数SRAMブロック、traceなしを要求。
PCMアクセスはBR=e0、RTSは偶数SRAMスタックに限定。条件外はH8へ戻す。
確保・ロック・スレッド移動は追加しない。

## 検証

- 14命令×384ケース＝5,376境界でH8と一致。
  PC/SR/全レジスタ/SRAM/ex_ignoreに加えPCMのRAM・ラッチ・チャンネル選択・
  更新フラグを比較。
- Release oracle: 379,676ステレオフレームがビット一致。
- H8 fallback: 2,909,664→2,861,092（48,572命令減少）。
- Mac Release Shared Codeビルド成功（署名なし）。

CPU改善量は未測定。3cd0以降の平滑化付き経路は未置換。

## 続き: 平滑化付き保持波形

3cd0..3d19の31命令を追加し、合計45命令を扱う。
PCM由来の値の取得は同じだが、現在値をブロック+30、目標を+28に保持し、
R6の歩幅で加減算して近づける。符号付き比較で目標を通り越す場合と
符号付きoverflowの場合は目標へ合わせ、+30/+32へ保存する。

3cd0はR6=0900を設定するが、直後の3cd3で0050に上書きされる。
この並びを意図の推測で変更せず、命令ごとの状態を保持した。
BLT/BGE/BGT相当の判定はN/V/Zを使う。

- 全45命令×384ケース＝17,280境界でPCM状態を含めH8と一致。
- Release oracle: 379,676ステレオフレームがビット一致。
- この再生のH8 fallbackは2,861,092で変化なし。
- Mac Release Shared Codeビルド成功（署名なし）。

今回の経路が全波形の実再生で検証されたという意味ではない。
CPU改善量は未測定。各単命令のガード外は引き続きH8へ戻る。
