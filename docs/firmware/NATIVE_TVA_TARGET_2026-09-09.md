[解析索引へ](../../FIRMWARE_RESEARCH_INDEX.md)

`TryEncodeTvaTarget`で365d..36a7/36adを一括C++計算。
前回値と目標値の差、同じ上位byte内での上向き丸め、シフトと指数テーブル、
更新値voice+30を扱う。前回値voice+28も更新する。RTSは別命令として残す。
前段の35db補間と命令数を合成して接続する。
正規v1.21 voice、CP/DP/EP=0、割り込みマスク7、traceなしが条件。
SR・全レジスタ・周辺装置を進める命令数を保持し、RT確保やロックは追加しない。

## 検証

- 4,352ケースでPC/SR/レジスタ/SRAM/命令数がH8と一致。
- 379,676ステレオフレームがビット一致。
- Mac Release Shared Code（署名なし）ビルド成功。
- 実再生H8 fallbackが4,998,480→4,763,697、234,783命令減少。
- ピッチ領域fallback=0を維持。
