# 割り込み可能なフィルターLFO合成

[解析索引へ](../../FIRMWARE_RESEARCH_INDEX.md)

再生中に残っていた47fbへの100回のH8 fallbackは、oracleのSR集計で
すべて割り込みマスク0と確認した。mask7を要するバッチの条件は変更せず、
`TryStepFilterModulation`を追加した。

47fb..4854の41命令を各1ステップで実行。分岐、符号反転、飽和、
積の上下word、丸めcarry、ADDXの累積ZとSUBXの通常Zを維持する。
レジスタ演算のみでDP/EPに依存せず、v1.21・CP=0・traceなしを要求。
debtを追加しないため、各命令後の割り込み状態が元のH8と一致する。
RTSは既存の単命令接続部へ戻す。確保・ロック・UI呼び出しは追加しない。

## 検証

- 41命令×384ケース＝15,744命令境界でPC/SR/レジスタ/SRAMが一致。
  mask0..7とSR下位16通り、乱数レジスタを含む。
- Release oracleで379,676ステレオフレームがビット一致。
- フィルター領域fallbackは6,783→5,283、全体は3,582,174→3,580,674。
  LFO入口のfallbackは消え、残り上位は473c以降のカットオフ変換。
- Mac Release Shared Codeを署名なしでビルド成功。

CPU時間・Logic内負荷は今回未測定。限定再生条件での領域の一部の確認であり、
全音色・全ROM・フィルター領域全体の置換完了ではない。
