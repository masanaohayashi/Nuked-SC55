# ボイスのパラメーター補正前段

`TryStepVoiceParameterBias`で39f6..3a6eの53命令を単命令C++化。

最初の補正はvoice[46]が指すパッチのbyte16から64を引き、
voice[-25]に加え、分岐に従って0/127へ飽和してvoice[-116]へ保存する。
次はパッチbyte17とvoice[168]から補正を作る。入力byteのbit7で方向を切り替え、
中心64からの差を倍化して加減算し、0/127へ制限する。
7312のword表を引き、必要な経路では符号反転し、voice[-124]へ保存する。
各パラメーターの音源仕様上の名称はこの範囲だけでは確定しない。

byte演算はレジスター上位byteを保持し、符号・carry・overflowを命令ごとに再現。
word演算へ進む際も上位byteを勝手にクリアしない。条件外の表indexはH8へ戻す。
v1.21、CP/DP=0、正規voice、traceなしを要求。パッチ読み取りはSRAM範囲、
表indexは偶数0..254に限定する。割り込みmaskやEPに依存しない。
確保・ロック・スレッド移動・周辺更新回数の変更はない。
