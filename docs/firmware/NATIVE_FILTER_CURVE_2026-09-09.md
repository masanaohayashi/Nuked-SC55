# フィルター補正テーブルの選択

TryStepFilterCurveでSC-55 v1.21の425b..428a、20命令を単命令置換。
c8fc[R1]とパッチbyte57を使ってページ3のdcf2テーブルを参照し、
間接参照したbyteをR4へ読む。DPを0に戻し、パッチbyte59と64の差を求める。
負側ではR3/R4をbyte反転、反転後R4が0ならffへ変更。その後128を引く。
ゼロの場合の42baへの分岐、LDCによるex_ignore、byte上位保持も再現。

EP=0のROM/SRAM、EP=1〜4のROMからのパッチ参照に対応。
dcf2テーブルは偶数インデックス0..510を対象とし、ガード外はH8へ戻す。
割り込み境界を維持し、動的確保・ロック・UI呼び出しは追加しない。

- 全20命令×384＝7,680境界でPC/SR/全レジスタ/DP/EP/ex_ignore/SRAM一致。
- 379,676ステレオフレームがビット一致。
- 同じ再生のH8 fallbackは2,855,467→2,854,992。
- Mac Release Shared Codeビルド成功（署名なし）。

428d..42baの19命令を追加、合計39命令。

128から加減算する。その値を67c6のwordテーブルで変換しvoice[-44]へ保存。
ゼロ補正の経路は256を直接保存する。byte乗算はR4全体を16ビット積で置換。
テーブル参照条件は679aが0..255、67c6が偶数0..510。
