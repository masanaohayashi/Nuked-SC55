# テーブル補間型LFOの単命令経路

`TryStepLfoSine`で3bee..3c30の29命令を追加。
ブロック+22の位相を進め、8000を中心に折り返した値から7412のbyte表の
隣接値を読み、下位byteを係数として線形補間する。結果を右へ1bit移し、
元位相が8000より大きければ符号を反転してブロック+32へ保存する。

NEG、byte乗算、byteレジスターの上位保持、各命令のSRとRAM状態を再現。
既存バッチが使えない割り込み可能経路を補完する。
v1.21、CP/DP=0、traceなし、偶数SRAMブロック、byte表index0..255を要求。
RTSは偶数SRAMスタックに限定。ガード外はH8へ戻る。
確保・ロック・スレッド移動・周辺更新回数の変更はない。

## 検証

- 29命令×384ケース＝11,136境界でPC/SR/全レジスタ/SRAMがH8と一致。
- Release oracle: 379,676ステレオフレームがビット一致。
- H8 fallback: 2,910,264→2,909,664（600命令減少）。
- Mac Release Shared Codeビルド成功（署名なし）。

CPU改善量は未測定。他波形の単命令経路3c31以降は未置換。

## 続き: 矩形・鋸歯状・折り返し波形

3c31..3cabの51命令を追加。ヘルパーは名前に反して他波形も含む計80命令を扱う。
矩形経路は位相8000を境に7fff/8001を出力する。
鋸歯状経路は位相から8000を引いた値を保存する。
折り返し経路は8000と4000の境界で分岐し、絶対値・倍化で形を作る。

注意: 3ca2はR3をNEGするが3ca4はR4を保存する。
一般的な三角波だと仮定してR3保存へ変更せず、実命令どおり再現した。
位相8000ちょうど、4000ちょうどの分岐先も保持する。
周辺更新や割り込み境界の間引きはない。

- 全80命令×384ケース＝30,720境界でPC/SR/全レジスタ/SRAMがH8と一致。
- Release oracle: 379,676ステレオフレームがビット一致。
- この再生のH8 fallbackは2,909,664で変化なし。
  今回の追加が別波形・ガード外経路の補完であることと矛盾しないが、
  全波形の再生確認を意味しない。
- Mac Release Shared Codeビルド成功（署名なし）。

CPU改善量は未測定。3cac以降の波形更新は未置換。
