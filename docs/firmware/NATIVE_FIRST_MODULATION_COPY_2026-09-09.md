# 第1変調系の共有登録・状態コピー

`TryStepFirstModulationCopy`で3d1a..3d8cの40命令を単命令C++化。
共有元voice[-2]からc84eの参照先を引き、自voiceの表要素へ保存する。
voice[-25]と-112..-96の9word、共有フラグ-115と-114のwordをコピーする。
3d44から入る経路はコピーの途中（-106）から始まる。

コピー後、-104がffffでなければ出力-122/-120/-118をクリアして戻る。
ffffなら-102を確認し、ffffであれば3e1e、それ以外は3d8fへ進む。
読み取りと書き込みを別命令として保ち、中間R6/SRと割り込み境界を維持する。

v1.21、CP/DP=0、正規voice、traceなしが条件。
共有元を読む時は共有元も正規voice、参照表indexは偶数0..46を要求。
RTSは偶数SRAMスタックに限定し、条件外はH8へ戻す。
新しい確保・ロック・スレッド移動・周辺更新の間引きはない。
