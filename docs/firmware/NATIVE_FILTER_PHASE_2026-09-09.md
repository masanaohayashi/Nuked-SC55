# フィルターEGの位相更新と補間

[解析索引へ](../../FIRMWARE_RESEARCH_INDEX.md)

`TryAdvanceFilterPhase`が45b6..4662をC++実行する。
durationが8以下なら目標値を直接出力。それ以外は524288/durationのレートと
AC5A+voice20（16bit折り返し）で位相10を進める。
上位wordが非ゼロなら65535超過分をレートで割り、余り時間をvoice20に保存。
位相がちょうど65535で上位wordがゼロの場合は補間経路に残る。

補間は始点84・目標86の符号で4通りに分岐する。異符号間の差分が
負符号になる場合は32767へ飽和するROMの演算をそのまま再現し、
通常の浮動小数点lerpに置き換えない。結果はvoice32へ書き込む。
最終MOVのNZ/Vクリア/C維持、積・商・余りを含むレジスタ、命令数を保持。

v1.21、CP/DP/EP=0、mask7、traceなし、正規voiceを要求する。
duration計算から連続実行する際は両方のdebtを合算し、周辺回路の時間を保つ。
既存audio経路で動作し、確保・ロック・UI呼び出しは追加しない。

## 検証

- 9,856ケースでH8とPC/SR/レジスタ/SRAM/命令数が一致。
  時間・位相の端点、乱数、始点/目標の符号境界、位相65535を含む。
- Release oracleで379,676ステレオフレームがビット一致。
- H8 fallbackは4,090,892→3,969,629（121,263命令減少）。
- Mac Release Shared Codeを署名なしでビルド成功。

CPU時間とLogic内負荷は今回未測定。命令数減少をCPU改善率とはしない。
4662以降の補正・PCM出力などは残存し、フィルターEG全体の置換完了ではない。
