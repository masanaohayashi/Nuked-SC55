# パッチからのボイス補正係数

TryStepVoicePatchScaleでSC-55 v1.21の4a4e..4ad7、50命令を単命令置換。

- ORCで割り込みをマスクし、voice[153]/[158]からパッチEP/R5を設定。
- パッチbyte18..22から64を減算してvoice[106..109]/[111]へ保存。
  4a64の追加減算も、次命令までのフラグを維持するため実行する。
- c914[R1]を読み、パッチbyte34と64との差が負なら補正値5個の符号を反転。
- 非ゼロ側は78c6/78dcテーブル、乗算結果の下位wordと加算を使用。
- パッチbyte16で78f2テーブルを参照し、係数を乗算、8000加算とADDXで丸める。
  byte34が64なら乗算を迂回し、テーブル値を直接使用する。
- 結果をvoice[-56]へ保存。

命令ごとのNZVC、byteレジスタ上位、ORC/LDCのex_ignore、ADDXの累積Zを維持。
パッチ参照はEP=0のROM/SRAMとEP=1..4のROM。テーブルindexは偶数0..510、
c914のR1は0..23を対象とし、それ以外はH8へフォールバックする。
割り込み境界を統合せず、RT経路の動的確保・ロック・UI処理は追加しない。

全体の置き換えは継続中。次の4ada以降の各補正値への適用はこのヘルパーの対象外。

## 検証

- 全50命令×384＝19,200境界でPC/SR/レジスタ/DP/EP/ex_ignore/SRAM/PCM状態一致。
- 379,676ステレオフレームがビット一致。
- 同じ再生のH8 fallbackは2,849,710→2,848,935。
- Mac Release Shared Codeビルド成功（署名なし）。
