# 共有ボイスの第3変調量

SC-55 v1.21、3db3..3e2dの53命令をTryStepSharedThirdDepthで置換。
パッチのバイアスとvoice[168]から符号付き深度を算出し、0..127の飽和、
7312テーブル変換、R6による係数適用を元の命令境界で再現する。
未スケール値はvoice[-124]、係数適用後はvoice[-118]に保存。
3e1e経路は先頭2深度をコピーしてR6=ffffで第3深度を計算する。

- 53命令×384ケース＝20,352境界でPC/SR/全レジスタ/SRAMがH8と一致。
- native-tva: 379,676ステレオフレームがビット一致。
- この再生のH8 fallbackは2,861,092で変化なし。
- Mac Release Shared Codeの署名なしビルド成功。

割り込み境界は維持し、バッチ化・スレッド変更・動的確保は追加しない。
CPU改善量およびLogic上の動作は今回未測定。
