# ボイス基準値の差分更新

TryStepVoiceBaseDifferenceでSC-55 v1.21の49ad..4a4d、57命令を単命令置換。
voice[-59]のbit5/7によって初期化・旧基準値との差分累積を選択する。

- c974[R1]がff以外なら1000倍し、現在のvoice[40]/[60]との差を求める。
- 旧値c8b2/c8aeと現在値の差は、voice[45]/[70]から減算する経路と、
  voice[43]/[66]へ加算する経路がある。
- bit7側ではvoice[43]/[66]に旧値を加え、現在値を引いて保存する。
- 最後にANDCで割り込みマスクを解除し、3個のNOPを個別に実行する。

上位byte・下位wordを個別命令で処理。ADDXの累積Z、SUBXの通常Z、
符号付きオーバーフローと桁上げ・桁借りを維持する。
R1のc974参照は0..23に限定し、範囲外や非対応ROMは既存H8経路へ戻す。
動的確保・ロック・UI呼び出しは追加しない。

テストは57命令それぞれ384状態（NZVCと全割り込みマスク、ランダムSRAM/レジスタ）
から1命令だけ実行し、H8デコーダーの結果と比較する。
